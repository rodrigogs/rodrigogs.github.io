# Fonts

Static TrueType instances used only by `scripts/render-cards.ts` (Satori needs TTF/OTF; the site itself loads the WOFF2 files from `@fontsource/*` and `@fontsource-variable/*` through the Astro Fonts API, see `astro.config.mjs`).

| File | Family | Role | Axes | Source |
|---|---|---|---|---|
| yellowtail-regular.ttf | Yellowtail | script (the name) | wght 400 | Google Fonts |
| luckiest-guy-regular.ttf | Luckiest Guy | display (titles) | wght 400 | Google Fonts |
| inter-regular.ttf | Inter | sans (reading) | wght 400 | Google Fonts |
| inter-semibold.ttf | Inter | sans | wght 600 | Google Fonts |
| inter-extrabold.ttf | Inter | sans | wght 800 | Google Fonts |
| orbitron-bold.ttf | Orbitron | hud (numerals) | wght 700 | Google Fonts |
| orbitron-black.ttf | Orbitron | hud | wght 900 | Google Fonts |
